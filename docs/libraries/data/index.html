ArturRios.Data

A modular data-access toolkit — nine packages covering EF Core, Dapper, MongoDB, DynamoDB and file export.

The largest library in the family: one consistent, envelope-based repository style across relational databases (EF Core over PostgreSQL, MySQL and SQLite, plus a Dapper read path), NoSQL stores (MongoDB, DynamoDB), and file export writers (CSV, JSON, TXT, MessagePack, Excel).

Every operation returns a DataOutput / ProcessOutput envelope from ArturRios.Output, so infrastructure failures — including optimistic-concurrency conflicts — surface as errors on the result instead of unhandled exceptions.

The nine packages

Each backend is its own package, so installing SQLite support does not pull in the MongoDB or AWS SDKs.

Install

dotnet add package ArturRios.Data.PostgreSql

Family dependencies

  • ArturRios.Output 3.1.0 — every package in the set depends on it, directly or through Relational.Core / Export.

Current package versions: Relational.Core 4.0.0, Dapper 4.0.0, PostgreSql 3.0.1, Sqlite 3.0.1, MySql 1.0, MongoDb 2.0.0, DynamoDb 2.0.0, Export 2.0.0, Export.Excel 2.0.0.
