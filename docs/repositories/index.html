This site

The site you are reading is built from dotnet-libraries. It carries no code — only the family-wide overview, the dependency graph and the shared patterns.

Contributing

Open the issue or pull request on the repository of the library it concerns. Anything about the family as a whole — a wrong dependency edge, a pattern worth documenting — belongs on dotnet-libraries.
