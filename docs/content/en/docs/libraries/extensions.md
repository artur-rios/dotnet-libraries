A small, fully unit-tested set of extension methods that make everyday .NET work more pleasant. No new
abstractions — just the methods the BCL leaves out.

## What you get

Extension methods over **strings**, **enums**, **collections**, **objects**, **dates**, **numbers**,
**comparisons** and **exceptions**.

## Install

```bash
dotnet add package ArturRios.Extensions
```

It can also be consumed as a Git submodule and referenced as a project, if you would rather build from
source.

## Family dependencies

- [`ArturRios.Util`](../util/) — and transitively [`ArturRios.Output`](../output/).
